# 🎵 SFX Generator (C++ / Qt6)

Быстрый и мощный генератор звуковых эффектов (SFX) для игр. Синтез происходит в реальном времени, а результат можно экспортировать в **OGG** (идеально для Godot), **WAV** или **MP3**.

## 🚀 Возможности
*   **Синтез:** Осцилляторы (sine, square, sawtooth, triangle), FM-модуляция, шум.
*   **Огибающие:** Классический ADSR + визуальный редактор огибающих (Volume и Pitch).
*   **Ритм:** Арпеджиатор и 16-шаговый степ-секвенсор.
*   **Эффекты:** LPF/HPF/BPF фильтры, Дисторшн (3 типа), Биткрашер, Дилэй (с пинг-понгом), Реверб, Хорус, Фэйзер, Тремоло, Ринг-мод.
*   **Управление:** X/Y-пад для частоты и громкости, тактильные крутилки (Knobs).
*   **Рисование:** Возможность рисовать огибающую звука прямо мышкой на осциллограмме.
*   **Экспорт:** Нативный OGG (с бесшовным лупом), WAV, MP3.

## 🛠 Сборка
Проект использует CMake и Qt 6.
Инструкция по сборке находится в файле `BUILD.md`.
